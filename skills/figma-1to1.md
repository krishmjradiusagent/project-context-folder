# Skill: Figma 1:1 Mapping

Use when task requires screenshot/Figma matching.

Process:
1. Extract frame size.
2. Extract layout grid.
3. Extract typography.
4. Extract spacing.
5. Extract component hierarchy.
6. Rebuild using existing components.
7. Compare screenshot/output.
8. Fix mismatches.

Never:
- Guess fonts.
- Guess spacing.
- Invent visual style.
