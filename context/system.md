# System Context

Product: Radius Agent CRM
Domain: Real estate CRM, transactions, offers, listings, auditing, CDA, envelopes, client collaboration.

Operating rules:
- Respect existing Radius patterns.
- Do not invent new UI patterns unless task explicitly asks.
- Use shadcn/ui + Tailwind tokens.
- Web: light mode default.
- Mobile: dark mode default.
- Quiet premium aesthetic: Airbnb/Zillow-like.
- WCAG-AA required.
- Role-aware UX: Agent, Team Lead, TC, Admin.
- Always cover empty, loading, error, permission, validation, and success states.
