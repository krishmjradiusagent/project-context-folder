# Design System Context

Component rules:
- Use shadcn/ui primitives.
- Use Radix behavior where needed.
- Use Tailwind semantic tokens.
- Do not hardcode arbitrary colors.
- Do not use oversized typography.
- Heading max: 24px.
- Prefer semibold headings.
- Maintain dense CRM layout for web.
- Prefer card-first mobile structure.

Common shadcn components:
- Button
- Card
- Dialog
- Sheet
- DropdownMenu
- Popover
- Tabs
- Table
- Badge
- Input
- Textarea
- Select
- Command
- Separator
- Tooltip
- Alert
- Skeleton
